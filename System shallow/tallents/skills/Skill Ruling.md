Skill development has certain rules:
1. At the class change character recieves a proficeincy in the weapon ( basic) that corelates to it
2. scroll comprahension limit - character on certain lvls can't gain powers, skills and etc. from scrolls that contain it:
	1. lvl 1-4 max common 
	2. lvl 5-8 max uncommon
	3. lvl 9-20 max rare
	4. lvl 21-50 max epic  
	5. above lvl 50 max legendary
	6. Mythic scrolls are lore expalined ones
3. every 4 lvl character may get one skill at lvl 1 or develop alredy posessed one
4. If the skill posess more than one development branch on it's tree, the main/demoinant one must be at least one point above the other ones. Only one branch can reach max development.
5. Scrolls may be degraded - high quality scrolls can be used as an upgrade to low reqirement skill, but not the other way around!
