## <font color="#1ad17e"> Results</font>
the players throw respectable amount of d6 from his table and counts points as follows in table :


| number on dice | points towards test  |
| -------------- | -------------------- |
| 1              | -1                   |
| 2,3            | 0                    |
| 4,5            | 1                    |
| 6              | 1 + throw a new dice |

the number on dm dice is the lilit that must be broken in order to past the test

##  <font color="#1ad17e">Reflective throw</font>

sometimes when an enemy is  forced to do a throw like a player the ammount of points is counted on both sides and  the winner is the one that has more, enemies also can rethrow and face the consequences of the [[fortune]]

## <font color="#1ad17e">Passive including tests</font>
Acording to Dm characters can create as many passives as they character could use (eq. character with in game lore of palladin path can have passive religion)
It's created with this equation :
$$ Statmaxdice+relatedStat/4 $$
example : passive intuition  (player's to roll dice's)+WisStat/4 ; eg.: 10dices+10wis/4=20/4=5 passive arcane


Respected passiver then is added to the result of the test.  
Tests that cn be passed with passive: in example above trival tests are auto passed and for easy (d6) tests player must throw when dm rolls 6 on it. If they aren't player performs a test as normal but add the passive at the end 


Technically in rare cases passive can be negative, if it happens autofails without a test, that's why it's advised to add passives at your own risk and only if DM allows.
